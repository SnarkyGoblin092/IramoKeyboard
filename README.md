# Iramo

Iramo is a custom keyboard for iPhone and iPad with 38 languages, word suggestions, auto-correction and swipe
typing. Its look and feel are yours to shape: themes, key styles, press effects, haptics and gestures, all set in
the Iramo app with the real keyboard to try them on. Everything it learns stays on the device.
